# Security policy

## Supported versions

Nictate is in public beta. Security fixes go into the latest release, and the latest release is the only one that
receives them.

## Reporting a vulnerability

Please don't open a public issue for a security problem. Report it privately instead:

1. Open the [Security tab](https://github.com/jrthormann/Nictate/security) of this repository.
2. Choose **Report a vulnerability** and describe the problem.

Include what you found, the steps to reproduce it, the Nictate version, and your macOS version. I'll acknowledge the
report and keep you updated until it is fixed.

## Scope

Nictate runs entirely on your Mac and has no server of its own. Its only network request is Check for Updates, which
runs when you ask for it. Reports about the update check, the history file, the clipboard, or screen capture are
all in scope.
